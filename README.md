# 🎮 SocialBalance
¿Podrás cumplir con todas tus responsabilidades sin descuidarte en el intento?

SocialBalance es un videojuego 2D de estilo pixel art, desarrollado en Java con Processing, donde tendrás que organizar tu tiempo, tomar decisiones y encontrar el equilibrio entre tus responsabilidades y tu bienestar.

Porque a veces el verdadero desafío no es terminar todas tus tareas, sino llegar al final del día sin quedarte sin energía.

🕹️ ¿De qué trata?

Imagina que tienes un montón de cosas por hacer, el reloj sigue avanzando y tu energía no es infinita.

En SocialBalance te pondrás en la piel de un estudiante que debe completar diferentes actividades mientras administra tres aspectos fundamentales:

⚡ Energía: no puedes hacerlo todo sin descansar.

🧠 Concentración: mantenerte enfocado también es parte del reto.

🔥 Estrés: cada decisión puede acercarte al límite.

Tendrás que decidir cuándo trabajar, cuándo descansar y cómo aprovechar tu tiempo. Parece sencillo, ¿verdad?

Bueno, intenta hacerlo antes de que se acabe el día.

🧩 Los desafíos

Las responsabilidades se convierten en pequeños minijuegos que pondrán a prueba diferentes habilidades.

Minijuego

Tu misión

🧠 Memoria

Pon a prueba tu capacidad para recordar.

✅ Verdadero o Falso

Decide qué afirmaciones son correctas.

🔗 Conectar Conceptos

Relaciona conceptos con sus definiciones.

🔐 Crear Contraseña

Aprende a construir contraseñas seguras.

📋 Ordenar Pasos

Organiza correctamente una secuencia de acciones.

Cada actividad tiene consecuencias sobre el tiempo y las estadísticas del personaje. No basta con resolver los desafíos: también debes administrar tus recursos.

🌙 Un día, muchas decisiones

Tu habitación será el punto de partida de la aventura.

Desde allí podrás interactuar con diferentes objetos:

💻 Escritorio: consulta tus responsabilidades y realiza las actividades.

📱 Celular: accede a las aplicaciones del juego.

🛏️ Cama: recupera energía descansando, pero recuerda que el tiempo no se detiene.

Cada acción cuenta. Dormir demasiado puede dejarte sin tiempo, pero trabajar sin descansar tampoco es una buena estrategia.

¿Qué tan bien administrarías tu propio día?

🛠️ ¿Cómo lo construimos?

SocialBalance está desarrollado con las siguientes tecnologías:

Java: lógica y programación del videojuego.

Processing: motor gráfico, animaciones e interacciones.

Pixel Art: personajes, escenarios e interfaces.

Git y GitHub: control de versiones y trabajo colaborativo.

También implementamos conceptos de programación orientada a objetos y estructuras de datos para organizar diferentes funcionalidades del juego.

Entre ellas se encuentran las listas enlazadas para administrar tareas, las pilas para operaciones de deshacer y los archivos secuenciales para guardar el progreso.

🚀 Ejecutar el proyecto

Descarga o clona este repositorio.

Instala Processing.

Abre el proyecto desde Processing en modo Java.

Ejecuta el archivo principal del videojuego.

¡Comienza a organizar tu día!

Nota: asegúrate de conservar la estructura de carpetas del proyecto para que los recursos gráficos y demás archivos funcionen correctamente.

🎯 ¿Qué buscamos?

Más allá de completar tareas, queremos que SocialBalance invite a reflexionar sobre la forma en que utilizamos nuestro tiempo.

Estudiar, descansar y distraerse son partes importantes de nuestra vida. El verdadero reto está en encontrar un equilibrio.

Y qué mejor manera de explorarlo que jugando.
